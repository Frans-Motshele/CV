# Frans Motshele — Personal Website CV

A personal CV website built with HTML and CSS, showcasing my background, skills, and projects in a clean, browser-based format.

---

## 🌐 Live Preview

Open `index.html` directly in your browser — no server or installation required.

---

## 🚀 How to Run

1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/Frans-Motshele/CV.git
   ```

2. **Navigate** into the project folder:
   ```bash
   cd CV
   ```

3. **Open** `index.html` in your browser:
   - Double-click the file in your file explorer, or
   - Right-click → *Open with* → your browser of choice

No build tools, frameworks, or dependencies needed.
